# EduTrack — Student Performance Analytics Portal

A fully responsive front-end prototype for a Student Performance Analytics Portal built using HTML5, CSS3, and JavaScript as part of a Web Development Internship — Week 1.

---

## 📌 Project Overview

EduTrack is a web-based portal designed to help educators and administrators monitor student academic performance, manage student records, and generate performance reports.

This is a **front-end prototype** — all data is hardcoded for demonstration purposes. 

---

## 📄 Pages

| File | Page | Description |
|------|------|-------------|
| `index.html` | Home | Welcome screen with stats, recent activity, and quick links |
| `dashboard.html` | Dashboard | Assignment progress, schedule, and upcoming tasks |
| `report.html` | Performance Report | Grade distribution, subject scores, and term history |
| `students.html` | Student Records | Registration form and full student records table |
| `about.html` | About | Mission, platform stats, features, and team |
| `contact.html` | Contact | Contact form and office information |

## ⚙️ Features

- **Responsive Design** — works on desktop, tablet, and mobile
- **Left Sidebar Navigation** — black sidebar with active page highlighting
- **Mobile Hamburger Menu** — sidebar slides in on small screens
- **Statistics Cards** — key academic metrics on Home and Dashboard
- **Progress Bars** — animated subject and assignment completion bars
- **Student Records Table** — 11 columns with search, status filter, and pagination
- **Form Validation** — student registration and contact forms with live error messages
- **Toast Notifications** — feedback messages on form submissions and actions
- **Footer Section** — consistent footer across all pages

## 🚀 How to Run

1. Download or clone this repository
2. Open the project folder in **VS Code**
3. Install the **Live Server** extension
4. Right-click `index.html` → **Open with Live Server**
5. Portal opens at `http://127.0.0.1:5500`

> No build tools, frameworks, or installations required.
